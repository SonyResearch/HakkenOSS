# Hakken ML Toolkit

Hakken ML Toolkit is a modular Python library designed to simplify machine learning workflows.  


## Features
- 🔧 **File Manager**: Manage local & cloud (S3) files seamlessly.
- 📉 **Losses**: Prebuilt & extensible PyTorch losses.
- 📊 **Metrics**: Accuracy, Precision, Recall, F1, MRR, Hits@K, etc.
- 🧩 **Base Structures**: Knowledge graphs, mappings, triples.
- ⚙️ **ML Utils**: YAML, IO, NetworkX, random utilities, timers.
- 🚀 **Optimizers**: Adam, SGD, schedulers (`on_plateau`, cosine).
- 📡 **Tracker**: Experiment logging via MLFlow, WandB, or filesystem.
