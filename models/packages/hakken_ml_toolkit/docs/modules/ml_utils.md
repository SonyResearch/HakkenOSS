# ML Utils

ML Utils is a Python package that provides various utility functions and classes for machine learning tasks. This repository contains a collection of modules designed to simplify common operations in data preprocessing and general utility functions for machine learning workflows.

## Features

- CSV operations (`csv.py`)
- Dictionary utilities (`dict.py`)
- I/O operations (`io.py`)
- Reproducibility helpers (`reproducibility.py`)
- Scalers implementation (MinMax scaler available)
- String manipulation utilities (`string.py`)
- TimersCollection for code execution measurement (`timer.py`)
- YAML file handling (`yaml.py`)
